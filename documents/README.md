# Webアプリケーション開発実習

**対象:** 高専生（プログラミング初心者）  
**所要時間:** 約1時間40分  
**内容:** PHPとMySQLを使った問い合わせフォームとお知らせCMSの作成

---

## 🎯 学習目標

この実習を通して、以下のスキルを習得します:

1. **Webアプリケーションの基本構造**を理解する
2. **データベース**との連携方法を学ぶ
3. **フォーム処理**（バリデーション・セッション管理）を実装する
4. **CRUD操作**（作成・読取・更新・削除）を実践する

## 🚀 実習の進め方

### 1. 環境起動

```bash
cd _docker
docker compose up -d
```

### 2. 各Chapterを順番に進める

- 各章のMarkdownファイルに記載されたコードを**そのままコピー&ペースト**
- 動作確認をして次のChapterへ

### 3. 困ったら

- エラーメッセージをよく読む
- コピペ箇所が正確か確認
